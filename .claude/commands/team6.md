## 보고 규칙

- **숫자를 바꾸지 마라.** 파일에 있는 값을 그대로 전달한다.
- **6팀은 차트 모양을 판정하지 않는다.** 등급은 검사 7개 중 실패 수(0=A, 1=B, 2 이상=C)일 뿐이다. "좋은 셋업", "깔끔한 베이스" 같은 말을 붙이지 마라.
- **등급이 높다고 더 잘 오른다는 증거는 아직 없다** (백테스트 2026-09-28: A등급 5건 0승, B등급 10건 5승 — 표본이 작아 결론 아님). 등급을 추천 강도처럼 말하지 마라.
- **수량(주)은 터미널에서만 계산한다.** 사용자가 물으면 `.env` 의 `ACCOUNT_USD` 로 계산해 알려주되, 파일·리포트·대시보드에는 쓰지 않는다 (저장소가 공개다).
- 모의 거래가 30건 미만이면 성적을 "관찰 단계"로 말하고 규칙 변경을 제안하지 마라.
- 6팀은 **실제 주문을 내지 않는다.** 체결은 자체 장부의 계산이다.
- 마지막에 대시보드 경로를 안내한다: `breakout-team/dashboard/breakout-room.html#t6`
